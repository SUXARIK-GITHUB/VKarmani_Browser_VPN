VKarmani Browser VPN 0.4.0 — Windows x64

ЭТО ОДНА ПАПКА ДЛЯ ПОЛЬЗОВАТЕЛЯ.
Никакие Hiddify, v2rayN, Xray, WARP или другие VPN-клиенты ставить не нужно.

ПЕРВЫЙ ЗАПУСК:
1. Дважды нажмите 00_INSTALL_VKARMANI.cmd.
   Скрипт сам установит локальный VKarmani Helper и сам получит проверенное ядро sing-box 1.14.1.
   Администратор Windows не нужен.
2. После успешной установки откроется папка расширения и страница расширений браузера.
3. Включите «Режим разработчика» -> «Загрузить распакованное расширение» и выберите ЭТУ ЖЕ папку.
4. Откройте VKarmani VPN, вставьте свою пользовательскую Remnawave subscription-ссылку и подключитесь.

ВАЖНО:
- Chrome/Chromium не разрешает самому расширению регистрировать Native Messaging host. Поэтому один запуск 00_INSTALL_VKARMANI.cmd — обязательный системный шаг безопасности браузера.
- После этого отдельный VPN-клиент пользователю не нужен.
- Для диагностики: powershell -ExecutionPolicy Bypass -File .\setup\diagnose.ps1
- Для удаления локального модуля: UNINSTALL_VKARMANI.cmd
